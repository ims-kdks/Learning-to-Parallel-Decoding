# Learning to Parallel Decoding

## How to run
1. Install dependencies
```
pip install -r requirements.txt
```
2. Run the program
   1. Test single questions
   ```
   python generate.py
   ```
   2. Run evaluations
   ```
   ./eval_llada.sh
   ```
